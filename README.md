## Was du brauchst

Für alle Skills brauchst du [Claude Code](https://claude.com/claude-code), in der Desktop-App oder im Terminal. Im normalen Claude-Chat im Browser laufen sie nicht. Was ein Baustein zusätzlich braucht, steht in seiner eigenen Anleitung.

## So holst du dir einen Skill

1. Oben auf dieser Seite auf den grünen Knopf **Code** klicken, dann **Download ZIP**. ZIP entpacken.
2. Die Anleitung im Ordner des Bausteins öffnen (die Datei `README.md`) und Schritt für Schritt durchgehen.

Du willst es noch einfacher? Öffne Claude Code und schreib: „Installiere mir den Skill aus diesem Ordner: …“ und häng den Pfad an. Den Rest erledigt Claude. Und wenn etwas hakt: Frag Claude Code direkt, gern mit einem Screenshot. Das ist kein Schummeln, genau dafür ist er da!

## Herkunft und Lizenzen

Jeder Baustein hat seine eigene Lizenz, sie steht in seiner Anleitung und als Datei `LICENSE` in seinem Ordner. Einen Überblick findest du in [LIZENZEN.md](LIZENZEN.md).
