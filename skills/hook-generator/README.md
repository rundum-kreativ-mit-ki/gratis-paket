# Hook-Generator: 27 Hooks zu jedem Thema, in zwei Registern

## Was es kann

Du nennst ein Thema, Claude liefert 27 Hooks für Reel, Post oder Karussell, nach Viralitäts-Potenzial sortiert, dazu eine Top 5 quer über beide Register:

- **21 Du-Hooks** in 7 Formeln (unbequeme Wahrheit, Countdown, Kontrast, Die Zahl, Scham-Hook, Die Frage, Der Widerspruch), 3 Hooks je Formel. Provokant, fragmentiert, mit Druck von außen.
- **6 Ich-Hooks** in 6 Winkeln (Zahl vorne weg, Gegen den Strich, Vorher-nachher, Fremde Autorität, Eingeständnis, Blick nach vorn). Genau zwei Zeilen, jede höchstens 40 Zeichen, Eingeständnis statt Angriff. Die Ich-Hooks sind in diesem Skill enthalten.

Dazu 14 weitere Formeln aus dem Reel-Alltag auf Zuruf. Zahlen und Erlebnisse erfindet der Skill nicht, fehlt dir eine Angabe, setzt er einen Platzhalter wie `[deine Zahl]`.

## Für wen

Für alle, die Inhalte für Instagram, LinkedIn oder TikTok machen und beim ersten Satz hängen bleiben. Du-Hooks tragen bei Themen wie Markt, Konkurrenz und Technik, Ich-Hooks bei deinem eigenen Weg, Preisen und Fehlern.

## Einrichtung Schritt für Schritt

Du brauchst [Claude Code](https://claude.com/claude-code), in der Desktop-App oder im Terminal.

1. Lade dieses Repo herunter: oben auf GitHub der grüne Knopf **Code**, dann **Download ZIP**. ZIP entpacken.
2. Öffne deinen persönlichen Skill-Ordner:
   - Windows: `C:\Users\DEINNAME\.claude\skills\`
   - Mac: `~/.claude/skills/`
3. Kopiere den Ordner `hook-generator` aus `skills/hook-generator/` dort hinein. Danach liegt da `skills\hook-generator\SKILL.md`.
4. Claude Code neu starten.
5. Schreiben: „Gib mir Hooks zum Thema …“
