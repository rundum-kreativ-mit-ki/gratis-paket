# Vermenschlichen: deutsche Texte ohne KI-Muster

## Was es kann

Claude schreibt oder überarbeitet deutsche Texte natürlich, sachlich und leserorientiert. Der Skill erhält Fakten und deine persönliche Stimme und reduziert schematische Sprachmuster: aufgeblähte Bedeutung, Werbesprache, vage Autoritäten, mechanische Verbindungswörter, Dreierschemata, Fazit-Bausteine, Fettdruck-Listen und technische Artefakte. Er erfindet keine Quellen und verspricht nie, dass ein Text von KI-Detektoren oder Wasserzeichen unerkannt bleibt.

Grundlage sind die Wikipedia-Sammlungen zu Anzeichen für KI-generierte Inhalte (deutsch und englisch), im Skill verlinkt.

## Für wen

Für alle, die auf Deutsch Artikel, E-Mails, Berichte, Anleitungen oder Social-Media-Texte schreiben und Entwürfe von KI überarbeiten wollen. Am besten für erklärende Texte, bei sehr persönlichem Stil nur als letzter Schliff.

## Einrichtung Schritt für Schritt

Du brauchst [Claude Code](https://claude.com/claude-code), in der Desktop-App oder im Terminal.

1. Lade dieses Repo herunter: oben auf GitHub der grüne Knopf **Code**, dann **Download ZIP**. ZIP entpacken.
2. Öffne deinen persönlichen Skill-Ordner:
   - Windows: `C:\Users\DEINNAME\.claude\skills\`
   - Mac: `~/.claude/skills/`
3. Kopiere den Ordner `vermenschlichen` aus `skills/vermenschlichen/` dort hinein. Danach liegt da `skills\vermenschlichen\SKILL.md`.
4. Claude Code neu starten.
5. Schreiben: „Vermenschliche diesen Text: …“
