# DSGVO-Ampel: darf ich das in ein KI-Tool eingeben?

## Was es kann

Du beschreibst einen Fall oder hängst eine Datei an, Claude gibt genau eine Farbe zurück: grün (rein damit), gelb (erst bereinigen, dann rein) oder rot (so nicht). Dazu ein Satz Begründung, bei Gelb die konkrete Liste, was raus muss, bei Rot ein gangbarer Weg. Die Farbe hängt davon ab, was eingegeben wird und wohin die Daten gehen (geschützter Geschäftstarif, offener Privat-Tarif oder lokales Modell).

Keine Rechtsberatung. Der Skill gibt eine schnelle Einordnung für Selbstständige und kleine Betriebe im DACH-Raum.

## Für wen

Für alle, die KI im Geschäft nutzen und vor dem Hochladen von Kundenlisten, Verträgen, Bewerbungen oder Rechnungen wissen wollen, ob das heikel ist.

## Einrichtung Schritt für Schritt

Du brauchst [Claude Code](https://claude.com/claude-code), in der Desktop-App oder im Terminal.

1. Lade dieses Repo herunter: oben auf GitHub der grüne Knopf **Code**, dann **Download ZIP**. ZIP entpacken.
2. Öffne deinen persönlichen Skill-Ordner:
   - Windows: `C:\Users\DEINNAME\.claude\skills\`
   - Mac: `~/.claude/skills/`
3. Kopiere den Ordner `dsgvo-ampel` aus `skills/dsgvo-ampel/` dort hinein. Danach liegt da `skills\dsgvo-ampel\SKILL.md`.
4. Claude Code neu starten.
5. Schreiben: „Darf ich diese Kundenliste bei ChatGPT eingeben?“ oder eine Datei anhängen und fragen, ob das datenschutzmäßig geht.
